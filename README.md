# UAM Autodiagnóstico de IA Responsable

Herramienta de autoevaluación ética y técnica para proyectos de IA en la Universidad Autónoma Metropolitana (UAM), basada en el Decálogo de Ética para el Uso de la IA en la UAM.

Aplicación cliente (SPA) sin backend ni claves de API. Los datos se guardan localmente en el navegador (localStorage).

## Ejecutar localmente

**Requisitos:** Node.js

1. Instalar dependencias:
   `npm install`
2. Ejecutar la app:
   `npm run dev`
